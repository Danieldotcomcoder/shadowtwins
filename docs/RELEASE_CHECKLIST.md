## To close the open gates

1. With a key and an agreed cap, run `OPENROUTER_API_KEY=... uv run python tools/pilot.py --cap 2.00`
   and review the printed plan, then run it again with `--yes`. Commit the regenerated
   `docs/research/PILOT_REPORT.md` and `pilot_results.json`, then re-run
   `tools/release_check.py --frontend`.
2. An independent reviewer repeats the commands in `docs/handoffs/P1.md`–`P5.md` and records findings.
3. Copy `docs/TRACKER.md` and the handoffs into Notion (`docs/HUB_SYNC.md`).
