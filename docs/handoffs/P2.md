## Remaining risks

* Tier T1 is exhaustively solved by the local-search baseline (a single-move scan); T1 difficulty
  rests on reasoning the scan, not search. T2/T3 separate from local search (73.0, 54.7).
* Partial credit is often coarse (median 2 intermediate levels) because entrance pairs change in
  groups when components split or merge.
* The refusal heuristic is English-only.
* Token counts exclude chat templates; billed usage will differ and is recorded by P3.
